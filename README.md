# Md Sahidullah — Academic Website

A minimalist, responsive academic portfolio prepared for GitHub Pages.

## Deploy

1. Extract this ZIP.
2. Review `index.html` and update any content or links you want to change.
3. Keep `assets/profile.png` and `assets/style.css` in the same relative locations.
4. Copy the files into the root of the `sahidullahmd.github.io` repository.
5. Commit and push to the `main` branch (or the branch configured for GitHub Pages).

No build step is required. This is a static HTML/CSS website and can be hosted directly by GitHub Pages.

## Notes

- Existing publication entries and academic information were migrated from the supplied `index.html`.
- The supplied portrait is used as the profile image.
- The page is responsive and includes a compact mobile navigation.
- Please verify publication metadata, email/phone visibility, and all external links before publishing.
